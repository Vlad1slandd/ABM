# Стоматологическая клиника «ABM» (Пятигорск)

Официальный высококонверсионный одностраничный сайт (Landing Page) для стоматологической клиники **«ABM»** (г. Пятигорск, ул. Орджоникидзе, 2).

Разработан в премиальной дизайн-концепции **Quiet Luxury / High-End Aesthetic Dentistry**.

---

## 💎 Особенности проекта

- **Дизайн и типографика:** выверенная эстетическая палитра (слоновая кость `#FBFBF9`, благородное шампанское золото `#C5A880`, графит `#1A1A1A`), типографика *Cormorant Garamond* и *Plus Jakarta Sans*.
- **Юридическая чистота (РФ):**
  - Полное соответствие требованиям **152-ФЗ** («О персональных данных») и **38-ФЗ** («О рекламе»).
  - Встроенные интерактивные модальные окна с Политикой конфиденциальности и Порядком согласия.
  - Обязательный медицинский дисклеймер согласно ст. 24 Федерального закона № 38-ФЗ.
  - Размеры шрифтов и дисклеймеров строго от 14px.
  - Независимость от внешних сервисов шрифтов (защита от утечки IP-адресов).
- **Интерактивные компоненты:**
  - Карусель реальных отзывов пациентов с плавным перелистыванием и автопрокруткой каждые 5 секунд.
  - Интеграция официальной интерактивной карты **Яндекс Карты API 2.1** с кастомной меткой клиники без рекламы конкурентов.
  - Плавная физическая анимация появления секций (Intersection Observer).
  - Прямые каналы связи в один клик: быстрый звонок и переход в WhatsApp с автозаполнением обращения: *«Здравствуйте! Хочу получить консультацию.»*.
- **Адаптивность:** безупречный отзывчивый интерфейс для Retina-экранов, планшетов и мобильных устройств (touch-friendly зоны не менее 48px).
